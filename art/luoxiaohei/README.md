# 罗小黑桌宠素材

本目录保存桌宠「罗小黑」的**真素材来源文件**与复现说明。

## source.webp

- 内容：用户提供的罗小黑（Luo Xiaohei）微信表情贴纸，动画贴纸。
- 规格：268×268，7 帧，每帧 100ms，不透明白底。
- 文件虽以 `.gif` 扩展名从微信导出，实际格式是动画 WebP（RIFF/WEBP），因此入库时使用真实扩展名 `.webp`，与源文件逐字节一致（md5 `b03e5149b403d1c52f43163dee20fbc9`）。
- 来源与授权：`licenseSource: "fandom-official-art-wechat-stickers-local"`（粉丝向官方微信表情，仅本地使用，`redistribution: "local-only"`，不随发布物对外分发）。

## 重新生成桌宠皮肤

旧的桌宠渲染层与去背景管线已随 2026-09-28 的内核重写移除。之后做桌宠时，从本目录的 `source.webp` 重新生成贴图：去掉与边缘连通的近白背景（阈值约 RGB ≥ 235，硬边、不做半透明渐变），再裁剪到各帧可见区域的并集（约 182×131）。
